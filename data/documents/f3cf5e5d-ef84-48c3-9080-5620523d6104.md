# Knowledge AI — Benchmark Test Document Dataset

This directory contains a complete, verified test document dataset engineered specifically for benchmarking Retrieval-Augmented Generation (RAG) applications, document chatbots, and citation engines.

## 1. Dataset Contents
The dataset comprises 10 primary operational documents simulating an institution of higher education and research (**Aethelgard Institute of Technology - AIT**), plus comprehensive benchmark query and evaluation suites:

| Filename | Document Subject | Primary Benchmark Targets |
| :--- | :--- | :--- |
| `01_project_overview.md` | System overview, purpose, and RAG architecture | Core architectural features, citation expectations, pipeline overview. |
| `02_student_handbook.md` | Academic rules, attendance, library hours, fines | Numerical thresholds, schedule lookups, fine calculations. |
| `03_it_support_policy.md` | IT hours, SLAs, passwords, campus Wi-Fi networks | Severity SLA matrix, technical rules, contact extensions. |
| `04_facility_guide.md` | Campus buildings, specialized labs, room booking rules | Spatial mappings, multi-tier reservation constraints, equipment loans. |
| `05_academic_calendar.md` | Semester timelines, Add/Drop dates, grade deadlines | Exact date/temporal retrieval, semester comparisons. |
| `06_employee_handbook.md` | Employment classifications, leave accrual, remote work | Tenure-based math tables, policy qualification rules. |
| `07_product_faq.md` | Knowledge AI product questions, hybrid search concepts | Keyword vs semantic search concepts, fallback thresholds. |
| `08_technical_documentation.md` | REST API specifications, chunking configs, technology stack | Technical schema, API payload parameters, JSON parsing. |
| `09_security_policy.md` | Data classification tiers, cryptographic rules, RBAC, incident SLAs | Security matrix lookups, multi-step incident workflows. |
| `10_department_directory.md` | Department heads, building/room numbers, contacts | Cross-document entity resolution and contact lookup. |
| `TEST_QUESTIONS.md` | 50 categorized benchmark questions | 8 distinct retrieval test categories. |
| `EXPECTED_RESULTS.md` | Reference answer key with citation targets | Evaluation scoring rubric and common failure modes. |

## 2. Ingestion & Upload Instructions
1. **Target Collection:** Create a collection or namespace named `ait-campus-knowledge` in your Knowledge AI instance.
2. **Ingest Order:** The documents can be uploaded concurrently or sequentially. Ensure all 10 `.md` files (`01_` through `10_`) are fully indexed before running tests.
3. **Chunking Settings:** For optimal parity with the benchmark design:
   * Target Chunk Size: **512 tokens**
   * Target Overlap: **64 tokens**
   * Header-aware boundary parsing enabled.

## 3. How to Run the Test Suite
1. Execute the 50 queries located in `TEST_QUESTIONS.md` against your RAG system endpoint (`POST /v1/query` or through the chat UI).
2. Record for each query:
   * Generated text answer.
   * Document citations returned.
   * Latency and retrieval metadata.
3. Compare each response against `EXPECTED_RESULTS.md`.

## 4. Evaluation Criteria & Identifying Failures
* **Retrieval Failure (Missed Context):** The model states it does not know the answer to a question in Categories 1–7.
  * *Diagnosis:* Lexical mismatch, semantic embedding distance too high, or `top_k` too small to capture all relevant chunks.
* **Citation Failure (Missing / Hallucinated Source):** The model answers correctly but fails to cite the source file, or cites a document that does not contain the fact.
  * *Diagnosis:* Citation attribution layer is decoupled from retrieved chunk IDs or prompt instructions are not strictly enforced.
* **Synthesis Failure (Partial Answer):** On multi-factor questions (e.g., Q32–Q36) or cross-document questions (e.g., Q24–Q31), the model only captures one part of the required answer.
  * *Diagnosis:* Reranker cutoff (`top_n`) is too aggressive or context window is truncated.
* **Hallucination Failure (False Information):** The model produces an answer for unanswerable questions (Q47–Q50) or invents external dates/rules.
  * *Diagnosis:* Similarity threshold cutoff is absent or prompt system instructions permit external pre-training knowledge.
