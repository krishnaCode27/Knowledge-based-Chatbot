# Knowledge AI — Project Overview

## 1. Executive Summary
**Knowledge AI** is an enterprise-grade, retrieval-augmented generation (RAG) platform designed to ingest semi-structured Markdown documentation, index text into high-dimensional vector embeddings, and provide context-grounded conversational answers. The primary objective is delivering auditable information with strict source citation guarantees, mitigating hallucinations in corporate and institutional knowledge environments.

## 2. Core Purpose and Mission
Organizations accumulate vast repositories of unstructured knowledge across departments. Traditional keyword search often fails to interpret semantic intent, while pure Large Language Models (LLMs) suffer from confabulation and lack verifiable audit trails. Knowledge AI addresses this by enforcing:
* **Deterministic Source Attribution:** Every generated claim must link directly to an indexed chunk and document URI.
* **Context Grounding:** The generative model is constrained to facts provided in the retrieved context window.
* **Knowledge Governance:** Clear access controls and verifiable source provenance for institutional compliance.

## 3. High-Level Architecture
Knowledge AI operates across three decoupled subsystems:
1. **Ingestion & Processing Pipeline:**
   * Markdown parser and frontmatter extractor.
   * Semantic header-aware chunker (target size: 512 tokens with 64-token overlap).
   * Vector embedding generator using dense bi-encoder models.
2. **Retrieval & Reranking Engine:**
   * Hybrid retrieval combining dense vector similarity (Cosine metric) and sparse lexical search (BM25).
   * Cross-encoder reranker filtering top-$K$ chunks to top-$N$ context candidates (default: $K=25$, $N=5$).
3. **Synthesis & Citation Module:**
   * Context assembly engine with system boundary prompts.
   * LLM inference engine generating markdown responses with bracketed inline citation tokens (e.g., `[Doc: 01_project_overview.md#Section-2]`).
   * Post-generation citation validation layer comparing claims against source chunk text.

## 4. Key Functional Features
* **Multi-Format Markdown Ingestion:** Parses standard CommonMark, tables, lists, and metadata blocks.
* **Strict Grounding Mode:** Reject queries with a polite fallback when cosine similarity falls below 0.62 or reranker confidence is under 0.40.
* **Hierarchical Metadata Tracking:** Chunks retain document ID, primary section header, subsection title, and line ranges.
* **Cross-Document Synthesis:** Aggregates facts across distinct operational domains (e.g., combining IT policies with facility reservation schedules).

## 5. Target Deployment Environments
The platform is packaged for cloud and on-premises deployment:
* **Containerized Workloads:** Docker container with Kubernetes Helm charts.
* **Fictional Testbed:** Deployed experimentally at **Aethelgard Institute of Technology (AIT)**, an independent research academy used as the canonical benchmark institution for this test dataset.
