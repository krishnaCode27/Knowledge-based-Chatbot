# Knowledge AI — Product Frequently Asked Questions (FAQ)

## 1. General Product Questions

### What file formats does Knowledge AI support for ingestion?
Knowledge AI natively supports Markdown files (`.md`, `.markdown`). The ingestion parser also handles UTF-8 encoded plain text (`.txt`) files provided they use Markdown-compliant heading structures (`#`, `##`, `###`). Proprietary binary formats like DOCX or PDF must be pre-converted to Markdown before ingestion.

### What is the maximum recommended file size for an uploaded document?
The ingestion parser is optimized for document files up to **10 MB** in size or approximately **150,000 words**. For larger corpuses (e.g., technical reference manuals over 500 pages), we recommend splitting documents into distinct modular chapters or topical files.

### How does the system handle source citations?
When answering a query, Knowledge AI embeds bracketed citation tags (e.g., `[Doc: 02_student_handbook.md#Library-Hours]`). Each citation references the source filename, section slug, and matching chunk metadata. The user interface renders these citations as interactive badges that highlight the extracted passage in an integrated document drawer.

## 2. Search, Retrieval and RAG Architecture

### What is the difference between keyword retrieval and semantic search?
* **Keyword Retrieval (Sparse Search / BM25):** Matches exact word occurrences, terms, and lexical stems. It is effective for distinct alphanumeric tokens, error codes (e.g., `ERR-503`), course codes (`SAFE-101`), or employee NetIDs.
* **Semantic Search (Dense Vector Retrieval):** Transforms text chunks into high-dimensional vector embeddings to evaluate conceptual and contextual similarity regardless of specific wording. It handles paraphrases, synonyms, and natural conversational phrasing.
* *Note:* Knowledge AI does not conflate the two; it utilizes a **Hybrid Retrieval** architecture where both sparse BM25 scores and dense vector cosine similarities are combined and normalized before passing to a cross-encoder reranker.

### Why does Knowledge AI occasionally state: "I do not have sufficient information in the provided documents to answer this question"?
Knowledge AI enforces a strict hallucination mitigation threshold:
1. If the top reranked context chunks fail to meet the minimum cosine similarity threshold (**0.62**) or reranker confidence score (**0.40**), the model declines to answer.
2. The system prompt instructs the language model never to invent external facts, extrapolation, or general world knowledge outside the provided document context.

## 3. Configuration and Administration

### How frequently does the vector index update when a file is modified?
Index updates depend on the ingestion mode configured:
* **Batch Ingestion:** Executes on a scheduled cron trigger (default: nightly at 02:00 UTC).
* **On-Demand Webhook:** Instantly re-chunks, embeds, and updates modified documents within approximately **3 to 10 seconds** per file.

### Can users restrict search queries to specific departmental folders?
Yes. Knowledge AI supports namespace filtering via metadata attributes. Users can supply an optional metadata filter in the API query payload (e.g., `{"department": "HR"}` or `{"document_type": "policy"}`).
